# Task 015-2 — Create Async Email Sending Task

## Parent User Story

[US-015 — Asynchronous Email Delivery](../USER_STORIES/user_story_015.md)

## Description

Create a Celery task that sends emails asynchronously, replacing the synchronous email sending in the request flow.

## Work to be Done

1. Create `core/tasks/email_tasks.py`:
   ```python
   @celery_app.task(bind=True, max_retries=3)
   def send_email_task(self, recipient, subject, body, html_body=None):
       try:
           # Send email using Flask-Mail or SMTP
           ...
       except Exception as exc:
           self.retry(exc=exc, countdown=60 * (self.request.retries + 1))
   ```
2. Implement retry with exponential backoff (1min, 2min, 3min)
3. Add error handling and logging
4. Include the correlation ID (if available) in task metadata
5. Handle different email types:
   - Account activation email
   - Password reset email (if US-002 implemented)
   - Error alert emails (for staging/prod)

## Expected Outcome

- Emails are sent asynchronously via Celery worker
- Failed sends are retried with exponential backoff

## Priority

**Medium**

## Acceptance Criteria

- [x] Email sending is performed in a Celery task
- [x] Failed sends are retried up to 3 times
- [x] Retry uses exponential backoff
- [x] Task errors are logged
- [x] Task accepts all email parameters (recipient, subject, body)
