# Task 015-5 — Add Dead Letter Queue and Failure Handling

## Parent User Story

[US-015 — Asynchronous Email Delivery](../USER_STORIES/user_story_015.md)

## Description

Implement a dead letter queue (DLQ) for email tasks that fail all retry attempts, and set up alerting for permanently failed emails.

## Work to be Done

1. Configure Celery to route permanently failed tasks to a DLQ:
   - Use `task_reject_on_worker_lost = True`
   - Implement `on_failure` callback to log and alert
2. Create a `FailedEmail` model or table to track failed deliveries:
   - recipient, subject, error_message, retries, failed_at
3. Send an alert (admin notification) when a task exhausts all retries
4. Create a management command to retry failed emails from the DLQ
5. Log all task state transitions

## Expected Outcome

- Failed emails are tracked and not silently lost
- Administrators are alerted about delivery failures
- Failed emails can be retried manually

## Priority

**Low**

## Acceptance Criteria

- [ ] Failed email tasks are recorded in the database or DLQ
- [ ] Admin alert is triggered after all retries are exhausted
- [ ] Management command can retry failed emails
- [ ] Task failures are logged with full context
