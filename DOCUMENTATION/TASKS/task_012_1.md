# Task 012-1 — Create GET /user/data Endpoint (Data Export)

## Parent User Story

[US-012 — GDPR Compliance Endpoints](../USER_STORIES/user_story_012.md)

## Description

Create an authenticated endpoint that exports all personal data for the authenticated user in a machine-readable JSON format.

## Work to be Done

1. Create `core/users/routes/gdpr.py`
2. Implement `GET /user/data`:
   - Require authentication via `@login_required` and `authorization_guard`
   - Collect all user data: profile info, login history, account metadata
   - Structure data in a comprehensive JSON format
   - Include: username, email, display_name, created_at, last_login, roles, profile data
   - Add data export metadata (export_date, format_version)
3. Register the route in the users blueprint
4. Log the data export request for audit purposes

## Expected Outcome

- Users can download their personal data as JSON
- Data export includes all stored information about the user

## Priority

**High**

## Acceptance Criteria

- [ ] `GET /user/data` returns a complete JSON export of user data
- [ ] All stored personal data fields are included
- [ ] Export metadata (date, version) is included
- [ ] Unauthenticated requests return 401
- [ ] Data export request is logged for audit
- [ ] Response includes `Content-Type: application/json`
