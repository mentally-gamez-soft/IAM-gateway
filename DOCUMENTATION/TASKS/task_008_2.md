# Task 008-2 — Update Nginx Dockerfile and Config for Non-Root Execution

## Parent User Story

[US-008 — Dockerize with Non-Root User](../USER_STORIES/user_story_008.md)

## Description

Configure the Nginx container to run as a non-root user with appropriate permissions and directory configurations.

## Work to be Done

1. Update `Docker/nginx/prod/Dockerfile`:
   - Create a non-root user for Nginx
   - Adjust ownership of Nginx directories (`/var/cache/nginx`, `/var/log/nginx`, `/etc/nginx/conf.d`)
   - Change the PID file location to a writable directory
   - Use `USER` directive before the entrypoint
2. Update `Docker/nginx/prod/nginx.conf`:
   - Add `pid /tmp/nginx.pid;` at the top level
   - Update temp paths: `client_body_temp_path /tmp/client_temp;`
   - Ensure the `listen` directive uses a port > 1024 (e.g., 8080) if running as non-root, or grant `NET_BIND_SERVICE` capability
3. Update `docker-compose-prod.yaml` port mapping if the internal Nginx port changes
4. Test the Nginx container starts correctly as non-root

## Expected Outcome

- Nginx runs as a non-root user
- Reverse proxy functionality is unchanged
- No security regression

## Priority

**High**

## Acceptance Criteria

- [ ] Nginx container process runs as a non-root user
- [ ] Reverse proxy correctly forwards to the Gunicorn container
- [ ] Log files and temp directories are writable
- [ ] No permission errors during operation
- [ ] Container builds and starts successfully
