# Task 002-4 — Create Password Reset Email Template and Sending Logic

## Parent User Story

[US-002 — Password Reset / Forgot Password Flow](../USER_STORIES/user_story_002.md)

## Description

Create an email template for the password reset notification and implement the sending logic using Flask-Mail. The email should contain a secure, time-limited reset link.

## Work to be Done

1. Create a password reset email template (HTML and plain text) including:
   - Greeting with username
   - Explanation that a password reset was requested
   - Reset link with the token embedded
   - Expiration notice (e.g., "This link expires in 30 minutes")
   - Security warning ("If you didn't request this, ignore this email")
2. Implement `send_password_reset_email(user, token)` function in the mail module
3. Construct the reset URL using `url_for` or a configurable base URL
4. Use the existing Flask-Mail `mail` instance for sending
5. Handle email sending failures gracefully (log error, don't expose to user)
6. Configurable: `PASSWORD_RESET_EMAIL_SUBJECT` in default config

## Expected Outcome

- Password reset emails are sent with a professional, secure message
- The reset link is correctly formed and contains the token
- Email sending errors are logged but do not affect the API response

## Priority

**High**

## Acceptance Criteria

- [ ] Password reset email is sent to the user's email address
- [ ] Email contains a valid reset link with the token
- [ ] Email includes the expiration time
- [ ] Email includes security warning text
- [ ] Both HTML and plain text versions are provided
- [ ] Email sending failure is logged but does not return an error to the user
- [ ] Email subject is configurable via environment settings
