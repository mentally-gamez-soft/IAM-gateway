# Task 004-5 — Write Tests for Logging Configuration

## Parent User Story

[US-004 — Structured JSON Logging](../USER_STORIES/user_story_004.md)

## Description

Write tests to verify that the logging configuration produces correct output in both JSON and text formats, and that context fields are properly included.

## Work to be Done

1. Create `tests/test_logging.py` with test cases:
   - JSON formatter produces valid JSON output
   - JSON log entry contains all required fields
   - Text formatter produces human-readable output
   - `request_id` is included in logs within a request context
   - `user_id` is included when user is authenticated
   - Logs outside request context do not raise errors
   - Environment-specific format is applied correctly
   - File handler writes to the correct path
2. Use a `StringIO` handler to capture log output for assertions
3. Test both formats independently

## Expected Outcome

- Logging configuration is fully tested
- Format switching between JSON and text is validated
- Context enrichment is verified

## Priority

**Medium**

## Acceptance Criteria

- [ ] At least 8 test cases covering the scenarios above
- [ ] JSON output is validated with `json.loads()`
- [ ] Context fields are verified present/absent as appropriate
- [ ] Tests pass in the CI pipeline
- [ ] No dependency on external logging infrastructure
