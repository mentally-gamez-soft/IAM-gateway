# Task 015-7 — Write Tests for Async Email Delivery

## Parent User Story

[US-015 — Asynchronous Email Delivery](../USER_STORIES/user_story_015.md)

## Description

Write tests verifying the async email delivery pipeline including task dispatch, retry behavior, and failure handling.

## Work to be Done

1. Create `tests/test_async_email.py` with test cases:
   - Task is dispatched (not executed synchronously) in production mode
   - Task executes synchronously with `CELERY_TASK_ALWAYS_EAGER = True`
   - Email is sent successfully via the task
   - Task retries on SMTP failure (up to 3 times)
   - Task uses exponential backoff for retries
   - Permanently failed task records the failure
   - Signup endpoint returns before email is sent
   - Email content is correct in the delivered message
2. Use Celery test utilities and `ALWAYS_EAGER` mode

## Expected Outcome

- Async email pipeline is validated by tests
- Retry and failure behaviors are verified

## Priority

**Medium**

## Acceptance Criteria

- [x] At least 8 test cases covering the scenarios above (12 tests implemented)
- [x] Task dispatch and execution are tested
- [x] Retry behavior is validated (full retry cycle tested via `task_eager_propagates=False`)
- [x] Failure handling is tested
- [x] All tests pass in CI
