# Task 005-1 — Implement /health Liveness Endpoint

## Parent User Story

[US-005 — Health Check and Readiness Probes](../USER_STORIES/user_story_005.md)

## Description

Create a `GET /health` liveness endpoint that returns HTTP 200 when the application process is running. This endpoint must be lightweight, unauthenticated, and exempt from CSRF protection.

## Work to be Done

1. Create `core/users/routes/health.py` module
2. Implement `GET /health` route returning:
   ```json
   {"status": "ok", "timestamp": "<ISO 8601>", "version": "<APP_VERSION>"}
   ```
3. Response status: HTTP 200
4. No authentication required
5. Exempt from CSRF protection
6. Response time target: < 10ms
7. Register the route in the users blueprint

## Expected Outcome

- `/health` endpoint returns 200 when the application is running
- The response includes the application version and timestamp
- No external dependency checks (pure liveness)

## Priority

**High**

## Acceptance Criteria

- [ ] `GET /health` returns HTTP 200 with JSON body
- [ ] Response includes `status`, `timestamp`, and `version` fields
- [ ] Endpoint does not require authentication
- [ ] Endpoint is exempt from CSRF protection
- [ ] Response time is under 100ms
- [ ] No database or external service calls are made
