# Task 010-6 — Write Tests Verifying Spec Accuracy

## Parent User Story

[US-010 — OpenAPI Specification Auto-Generation](../USER_STORIES/user_story_010.md)

## Description

Write automated tests that verify the generated OpenAPI spec contains all expected endpoints, schemas, and metadata.

## Work to be Done

1. Create `tests/test_openapi_spec.py` with test cases:
   - Spec is valid JSON and parseable
   - Spec contains all expected endpoint paths
   - Each endpoint has request and response schemas
   - Error responses are documented
   - API metadata (title, version) matches config
   - Authentication scheme is defined
2. Fetch the spec from the running test app (GET `/openapi.json`)
3. Validate against the OpenAPI 3.0 schema programmatically

## Expected Outcome

- Spec accuracy is validated in CI
- Missing or incorrect documentation is caught automatically

## Priority

**Low**

## Acceptance Criteria

- [ ] At least 6 test cases covering spec structure
- [ ] Tests verify endpoint paths match registered routes
- [ ] Schema definitions are validated for completeness
- [ ] Tests fail if a new endpoint is added without schema documentation
- [ ] Tests pass in CI
