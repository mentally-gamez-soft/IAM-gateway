# Task 013-1 — Create Request Correlation ID Middleware

## Parent User Story

[US-013 — Request Correlation ID Tracking](../USER_STORIES/user_story_013.md)

## Description

Create a Flask before-request middleware that generates or extracts a unique correlation ID for every incoming request.

## Work to be Done

1. Create `core/auth/middlewares/correlation_id.py`
2. Implement the middleware:
   - Extract `X-Correlation-ID` or `X-Request-ID` from incoming request headers
   - If not present, generate a new UUID4 as the correlation ID
   - Store the correlation ID in Flask's `g` object: `g.correlation_id`
   - Set the header on the response via `after_request` hook: `X-Correlation-ID`
3. Register the middleware in `core/__init__.py` (in `create_app`)
4. Ensure the middleware runs before authentication checks

## Expected Outcome

- Every request/response pair has a correlation ID
- Existing correlation IDs from upstream services are preserved

## Priority

**Medium**

## Acceptance Criteria

- [ ] Incoming `X-Correlation-ID` header is preserved through the request
- [ ] Missing correlation ID is auto-generated as UUID4
- [ ] Response includes `X-Correlation-ID` header
- [ ] Correlation ID is accessible via `g.correlation_id` within request context
- [ ] Middleware runs before all other processing
