# Task 006-3 — Update Swagger Configuration for Versioned Paths

## Parent User Story

[US-006 — API Versioning Strategy](../USER_STORIES/user_story_006.md)

## Description

Update the Swagger/OpenAPI documentation to reflect the new versioned URL paths (`/api/v1/...`).

## Work to be Done

1. Update `static/swagger-docs/swagger.json`:
   - Change `basePath` or `servers` to include `/api/v1`
   - Update all path definitions to remove the dynamic prefix
2. Update `core/swagger/swagger_config.py` if the API URL reference needs changing
3. Verify Swagger UI correctly renders the versioned paths
4. Add API version info to the Swagger spec metadata
5. Test the "Try it out" feature works with versioned endpoints

## Expected Outcome

- Swagger documentation reflects the correct versioned endpoints
- The "Try it out" feature targets the `/api/v1/` paths

## Priority

**Medium**

## Acceptance Criteria

- [ ] Swagger spec paths use `/api/v1/` prefix
- [ ] Swagger UI renders without errors
- [ ] "Try it out" sends requests to the correct versioned endpoints
- [ ] API version is visible in the spec metadata
