# Task 014-5 — Create POST /2fa/disable Endpoint

## Parent User Story

[US-014 — Two-Factor Authentication (2FA)](../USER_STORIES/user_story_014.md)

## Description

Create an endpoint to disable 2FA on the user's account, requiring password confirmation.

## Work to be Done

1. In `core/users/routes/two_factor.py`, implement `POST /2fa/disable`:
   - Require authentication
   - Require password confirmation: `{"password": "..."}`
   - Validate the password
   - Clear the TOTP secret and recovery codes
   - Set `is_2fa_enabled = False`
   - Log the 2FA disabling event
2. Optionally require a valid TOTP code in addition to password

## Expected Outcome

- Users can disable 2FA with password confirmation
- TOTP secrets are securely removed

## Priority

**Medium**

## Acceptance Criteria

- [ ] `POST /2fa/disable` disables 2FA with valid password
- [ ] TOTP secret and recovery codes are cleared from the database
- [ ] `is_2fa_enabled` is set to `False`
- [ ] Invalid password is rejected
- [ ] Event is logged for audit
- [ ] Unauthenticated requests return 401
