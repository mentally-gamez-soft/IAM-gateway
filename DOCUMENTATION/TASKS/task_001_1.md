# Task 001-1 — Set up Redis and Flask-Limiter Dependencies

## Parent User Story

[US-001 — Rate Limiting on Authentication Endpoints](../USER_STORIES/user_story_001.md)

## Description

Install and configure the foundational dependencies required for rate limiting: `Flask-Limiter` as the rate limiting extension and `redis` as the backend storage for tracking request counts in a distributed environment (multiple Gunicorn workers).

## Work to be Done

1. Add `flask-limiter>=3.5.0` and `redis>=5.0.0` to `pyproject.toml` dependencies
2. Update `requirements.txt` via `uv pip compile`
3. Verify compatibility with the existing Flask 3.1.x and Python 3.11+ stack
4. Create a basic initialization of `Flask-Limiter` in `core/__init__.py` within the `create_app` factory
5. Configure the limiter to use Redis as the storage backend via `RATELIMIT_STORAGE_URI` environment variable

## Expected Outcome

- `Flask-Limiter` and `redis` packages installed and importable
- `Limiter` instance created and attached to the Flask app
- Redis URI configurable via environment variable (defaulting to `redis://localhost:6379/0`)
- Application starts without errors with the new dependencies

## Priority

**Critical**

## Acceptance Criteria

- [ ] `flask-limiter` and `redis` are listed in `pyproject.toml` and `requirements.txt`
- [ ] `Limiter` instance is initialized in the app factory with Redis backend
- [ ] Application starts successfully with the limiter configured
- [ ] Redis connection failure is handled gracefully (fallback to in-memory or log warning)
- [ ] No existing tests are broken by the new dependency
