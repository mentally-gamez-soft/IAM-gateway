# Task 007-3 — Expose Pool Metrics at Health Endpoint

## Parent User Story

[US-007 — Database Connection Pooling and Health Monitoring](../USER_STORIES/user_story_007.md)

## Description

Add database connection pool metrics to the `/ready` or `/health` endpoint so that operators can monitor pool utilization.

## Work to be Done

1. In the readiness endpoint (from US-005), add pool metrics:
   - `pool_size`: configured pool size
   - `checked_out`: currently checked-out connections
   - `checked_in`: connections available in the pool
   - `overflow`: current overflow connections
   - `max_overflow`: configured max overflow
2. Access metrics via `db.engine.pool.status()` or pool attributes
3. Include metrics in the `/ready` response under a `database.pool` key
4. Add warning indicators if pool utilization exceeds 80%

## Expected Outcome

- Pool metrics are visible in the health endpoint
- Operators can monitor connection pool saturation

## Priority

**Low**

## Acceptance Criteria

- [ ] Pool metrics are included in the `/ready` response
- [ ] Metrics include pool_size, checked_out, checked_in, overflow values
- [ ] High pool utilization (>80%) is flagged in the response
- [ ] Metrics do not add significant latency to the health check
