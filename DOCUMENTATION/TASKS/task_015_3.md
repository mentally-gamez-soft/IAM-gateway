# Task 015-3 — Replace Synchronous Email Calls with Task Dispatch

## Parent User Story

[US-015 — Asynchronous Email Delivery](../USER_STORIES/user_story_015.md)

## Description

Replace all synchronous email sending calls in route handlers with Celery task dispatches.

## Work to be Done

1. Update `core/users/routes/signup.py`:
   - Replace direct email sending with `send_email_task.delay(recipient, subject, body)`
2. Update `core/users/routes/email_activation.py` if it sends any emails
3. Update `server/config/mails.py` — ensure the mail sending function can work both inside and outside Flask context
4. Update error alert emails in `server/config/logs.py` (staging/prod `SMTPHandler`) — consider keeping these synchronous for reliability
5. Add a configuration flag `USE_ASYNC_EMAIL` to optionally disable async for testing
6. In testing config, set `USE_ASYNC_EMAIL = False` and use `CELERY_TASK_ALWAYS_EAGER = True`

## Expected Outcome

- API responses don't wait for email delivery
- Improved response times for signup and activation
- Testing falls back to synchronous execution

## Priority

**Medium**

## Acceptance Criteria

- [ ] Signup no longer blocks on email send
- [ ] Activation emails are sent via Celery task
- [ ] Testing mode runs tasks synchronously (eager)
- [ ] API response time improves for email-sending endpoints
- [ ] Existing email functionality is unchanged from the user's perspective
