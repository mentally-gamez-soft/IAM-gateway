# Task 004-4 — Configure Environment-Specific Log Formats

## Parent User Story

[US-004 — Structured JSON Logging](../USER_STORIES/user_story_004.md)

## Description

Configure the logging system to use JSON format in staging/production and human-readable text format in local/dev/testing environments.

## Work to be Done

1. Update `configure_logging()` in `server/config/logs.py` to check the `LOG_FORMAT` config variable
2. If `LOG_FORMAT == "json"`: use `JsonLogFormatter` for both console and file handlers
3. If `LOG_FORMAT == "text"`: use the existing `logging_formatter()` for human-readable output
4. Configure per environment in config files:
   - `config/local.py`: `LOG_FORMAT = "text"`
   - `config/testing.py`: `LOG_FORMAT = "text"`
   - `config/dev.py`: `LOG_FORMAT = "text"`
   - `config/staging.py`: `LOG_FORMAT = "json"`
   - `config/prod.py`: `LOG_FORMAT = "json"`
5. Update the SMTP mail handler formatter to a JSON-compatible format if needed

## Expected Outcome

- Developers see human-readable logs in local/dev environments
- Production/staging logs are machine-parseable JSON
- Switching format requires only a config change

## Priority

**Medium**

## Acceptance Criteria

- [ ] Local/dev environments produce human-readable text logs
- [ ] Staging/production environments produce JSON-formatted logs
- [ ] Changing `LOG_FORMAT` in config switches the format without code changes
- [ ] File handler and console handler both use the configured format
- [ ] SMTP handler formatting is updated for consistency
