# Task 009-1 — Install Flask-CORS and Configure in App Factory

## Parent User Story

[US-009 — CORS Configuration](../USER_STORIES/user_story_009.md)

## Description

Install the `Flask-CORS` extension and initialize it in the Flask application factory with default configuration.

## Work to be Done

1. Add `flask-cors>=4.0.0` to `pyproject.toml`
2. Update `requirements.txt`
3. In `core/__init__.py`, import and initialize CORS:
   ```python
   from flask_cors import CORS
   ```
4. In `create_app()`, after blueprint registration:
   ```python
   CORS(app,
       origins=app.config.get("CORS_ORIGINS", "*"),
       methods=app.config.get("CORS_METHODS", ["GET", "POST", "PUT", "DELETE", "OPTIONS"]),
       allow_headers=app.config.get("CORS_ALLOW_HEADERS", ["Content-Type", "Authorization", "X-CSRFToken"]),
       expose_headers=app.config.get("CORS_EXPOSE_HEADERS", ["X-CSRFToken"]),
       supports_credentials=app.config.get("CORS_SUPPORTS_CREDENTIALS", True),
       max_age=app.config.get("CORS_MAX_AGE", 600)
   )
   ```
5. Add default CORS settings to `config/default.py`
6. Verify OPTIONS preflight requests work correctly

## Expected Outcome

- CORS headers are present in API responses
- Preflight OPTIONS requests are handled correctly
- Configuration is sourced from environment settings

## Priority

**Medium**

## Acceptance Criteria

- [ ] `flask-cors` is installed and initialized in the app factory
- [ ] API responses include `Access-Control-Allow-Origin` header
- [ ] `OPTIONS` preflight requests return correct CORS headers
- [ ] `Access-Control-Allow-Credentials: true` is set
- [ ] No existing tests are broken
