# Task 010-1 — Install flask-smorest and Marshmallow Dependencies

## Parent User Story

[US-010 — OpenAPI Specification Auto-Generation](../USER_STORIES/user_story_010.md)

## Description

Install the required dependencies for auto-generating OpenAPI specifications: `flask-smorest` for API integration and `marshmallow` for schema definitions.

## Work to be Done

1. Add to `pyproject.toml`:
   - `flask-smorest>=0.44.0`
   - `marshmallow>=3.20.0`
2. Update `requirements.txt`
3. Verify compatibility with Flask 3.1.x
4. Configure `flask-smorest` API metadata in `core/__init__.py`:
   ```python
   app.config["API_TITLE"] = app.config.get("APP_NAME")
   app.config["API_VERSION"] = app.config.get("APP_VERSION")
   app.config["OPENAPI_VERSION"] = "3.0.3"
   app.config["OPENAPI_URL_PREFIX"] = "/"
   app.config["OPENAPI_SWAGGER_UI_PATH"] = "/swagger"
   app.config["OPENAPI_SWAGGER_UI_URL"] = "https://cdn.jsdelivr.net/npm/swagger-ui-dist/"
   ```
5. Verify Swagger UI is served from `flask-smorest` configuration

## Expected Outcome

- Dependencies installed and configured
- `flask-smorest` API object initialized
- Swagger UI accessible at `/swagger`

## Priority

**Medium**

## Acceptance Criteria

- [ ] `flask-smorest` and `marshmallow` are installed without conflicts
- [ ] API metadata is configured from application config
- [ ] Swagger UI is accessible at the configured URL
- [ ] No existing functionality is broken
