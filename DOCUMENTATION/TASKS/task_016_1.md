# Task 016-1 — Create Database Backup Script

## Parent User Story

[US-016 — Automated Database Backup Strategy](../USER_STORIES/user_story_016.md)

## Description

Create a shell script that performs automated PostgreSQL database backups using `pg_dump`.

## Work to be Done

1. Create `scripts/db_backup.sh`:
   - Accept parameters: database name, host, port, user, backup directory
   - Source credentials from environment variables
   - Use `pg_dump` with custom format (compressed): `pg_dump -Fc`
   - Generate a timestamped filename: `iam_gateway_YYYYMMDD_HHMMSS.dump`
   - Verify the backup was created successfully
   - Set appropriate file permissions (600)
2. Add error handling and logging
3. Create a configuration file `scripts/backup_config.env` with default parameters
4. Make the script executable with proper shebang

## Expected Outcome

- A single command produces a timestamped database backup
- Backups are compressed and secured

## Priority

**Medium**

## Acceptance Criteria

- [ ] Script produces a valid, compressed database backup
- [ ] Backup filename includes the timestamp
- [ ] File permissions are set to 600
- [ ] Script exits with non-zero code on failure
- [ ] Credentials are sourced from environment variables
- [ ] Script is documented with usage instructions
