# Task 008-4 — Test Container Startup and Functionality as Non-Root

## Parent User Story

[US-008 — Dockerize with Non-Root User](../USER_STORIES/user_story_008.md)

## Description

Perform end-to-end testing to verify that both the application and Nginx containers work correctly when running as non-root users.

## Work to be Done

1. Build both dev and prod Docker images with the non-root configuration
2. Start the containers via `docker compose up`
3. Verify:
   - Application responds to HTTP requests
   - Nginx reverse proxy functions correctly (prod)
   - Log files are written
   - `docker exec <container> whoami` returns the non-root user
   - `docker exec <container> id` shows UID 1000
4. Run the existing test suite against the containerized application
5. Verify `docker inspect` shows the correct user configuration
6. Test container restart behavior

## Expected Outcome

- All containers run as non-root with full functionality
- No regressions in application behavior

## Priority

**Medium**

## Acceptance Criteria

- [ ] Both dev and prod containers start successfully as non-root
- [ ] HTTP requests are served correctly
- [ ] Nginx reverse proxy works in prod configuration
- [ ] Container restart does not cause permission issues
- [ ] `docker exec` confirms non-root user
