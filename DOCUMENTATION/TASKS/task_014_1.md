# Task 014-1 — Implement TOTP Secret Generation and Storage

## Parent User Story

[US-014 — Two-Factor Authentication (2FA)](../USER_STORIES/user_story_014.md)

## Description

Add the ability to generate and securely store TOTP (Time-based One-Time Password) secrets for users who enable 2FA.

## Work to be Done

1. Add `pyotp>=2.9.0` and `qrcode>=7.4.0` to `pyproject.toml`
2. Update `requirements.txt`
3. Add 2FA fields to `GwUser` model:
   - `totp_secret` — `db.Column(db.String(32), nullable=True)` (encrypted at rest)
   - `is_2fa_enabled` — `db.Column(db.Boolean, default=False)`
   - `recovery_codes` — `db.Column(db.Text, nullable=True)` (encrypted at rest)
   - `two_fa_enabled_at` — `db.Column(db.DateTime, nullable=True)`
4. Create Alembic migration for new fields
5. Implement TOTP secret generation utility:
   ```python
   import pyotp
   secret = pyotp.random_base32()
   totp = pyotp.TOTP(secret)
   ```
6. Generate recovery codes (8 single-use codes) utility function
7. Encrypt TOTP secret and recovery codes before storage

## Expected Outcome

- TOTP secrets can be generated and stored securely
- Recovery codes are generated as a backup authentication method

## Priority

**High**

## Acceptance Criteria

- [ ] TOTP secrets are generated using `pyotp`
- [ ] Secrets are stored encrypted in the database
- [ ] Recovery codes (8 codes) are generated and stored encrypted
- [ ] Alembic migration runs successfully
- [ ] Existing users are unaffected (2FA is opt-in)
