# Task 006-4 — Update All Tests to Use Versioned Routes

## Parent User Story

[US-006 — API Versioning Strategy](../USER_STORIES/user_story_006.md)

## Description

Update the test suite to target the new versioned API routes (`/api/v1/...`) and verify that legacy routes still work with deprecation headers.

## Work to be Done

1. Update `tests/test_standard_routes.py`:
   - Change all API calls from `/signup`, `/login`, `/logout`, etc. to `/api/v1/signup`, `/api/v1/login`, `/api/v1/logout`, etc.
   - Update helper methods (`login()`, `signup()`, etc.) in the base test class
2. Add test cases for legacy routes:
   - Legacy `/signup` returns the same response as `/api/v1/signup`
   - Legacy responses include `Deprecation` header
   - Legacy responses include `Sunset` header
3. Add a test verifying that unknown API version returns 404 (e.g., `/api/v99/signup`)
4. Verify no test regressions

## Expected Outcome

- All tests target the versioned endpoints
- Legacy route deprecation is validated by tests
- Full test suite passes

## Priority

**High**

## Acceptance Criteria

- [ ] All API test calls use `/api/v1/` prefix
- [ ] At least 3 tests validate legacy route deprecation headers
- [ ] Full test suite passes without regressions
- [ ] Test for invalid API version returns 404
