# Task 011-3 — Create PUT /profile Endpoint

## Parent User Story

[US-011 — User Profile Management](../USER_STORIES/user_story_011.md)

## Description

Create an authenticated endpoint that allows users to update their profile information.

## Work to be Done

1. In `core/users/routes/profile.py`, implement `PUT /profile`:
   - Require authentication via `@login_required` and `authorization_guard`
   - Accept JSON body with updatable fields: display_name, avatar_url, bio, language_preference, timezone
   - Validate input (field lengths, allowed values for language/timezone)
   - Update the user model and set `profile_updated_at` to current timestamp
   - Commit changes to the database
   - Return updated profile data
2. Create form or validation schema for profile update (e.g., `ProfileUpdateForm` or marshmallow schema)
3. Prevent updating protected fields (email, username, role) through this endpoint

## Expected Outcome

- Users can update their profile through the API
- Input is validated; protected fields cannot be changed

## Priority

**Medium**

## Acceptance Criteria

- [ ] `PUT /profile` updates the authenticated user's profile
- [ ] Validation rejects invalid field values
- [ ] Protected fields (email, username, role) are not modifiable via this endpoint
- [ ] `profile_updated_at` is set on update
- [ ] Unauthenticated requests return 401
- [ ] CSRF token is required
