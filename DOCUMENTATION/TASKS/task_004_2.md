# Task 004-2 — Implement JSON Log Formatter

## Parent User Story

[US-004 — Structured JSON Logging](../USER_STORIES/user_story_004.md)

## Description

Create a custom JSON log formatter class that produces structured log entries with all required fields.

## Work to be Done

1. Create a new `JsonLogFormatter` class in `server/config/logs.py` extending `pythonjsonlogger.jsonlogger.JsonFormatter`
2. Override `add_fields()` to include:
   - `timestamp` (ISO 8601 format)
   - `level` (log level name)
   - `logger` (logger name)
   - `function` (calling function name)
   - `lineno` (line number)
   - `request_id` (from Flask `g` object, if available)
   - `user_id` (from current user, if authenticated)
   - `message` (log message)
   - `environment` (current app environment)
3. Handle cases where Flask request context is not available (startup logs, background tasks)
4. Ensure the formatter produces valid JSON on every line

## Expected Outcome

- Structured JSON log entries with all required fields
- Safe handling of missing request context
- Valid JSON output parseable by log aggregation tools

## Priority

**High**

## Acceptance Criteria

- [ ] Log entries are valid JSON when parsed by `json.loads()`
- [ ] All specified fields are present in each log entry
- [ ] Missing context fields (e.g., `request_id` outside request) default to `null` (not cause errors)
- [ ] Timestamps are in ISO 8601 format
- [ ] Unicode characters in messages are correctly encoded
