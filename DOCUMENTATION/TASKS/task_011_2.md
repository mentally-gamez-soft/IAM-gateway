# Task 011-2 — Create GET /profile Endpoint

## Parent User Story

[US-011 — User Profile Management](../USER_STORIES/user_story_011.md)

## Description

Create an authenticated endpoint that returns the current user's profile information.

## Work to be Done

1. Create `core/users/routes/profile.py`
2. Implement `GET /profile` endpoint:
   - Require authentication via `@login_required` and `authorization_guard`
   - Retrieve the authenticated user's profile
   - Return profile data using `to_profile_dict()` method
   - Include fields: username, email, display_name, avatar_url, bio, language, timezone, created_at, last_modified
3. Register the route in the users blueprint
4. Handle edge cases: profile not found, deleted user

## Expected Outcome

- Authenticated users can retrieve their profile information
- Profile data is returned as JSON

## Priority

**Medium**

## Acceptance Criteria

- [ ] `GET /profile` returns the user's profile data
- [ ] Unauthenticated requests return 401
- [ ] Response includes all profile fields
- [ ] CSRF token is required (or endpoint is read-only and exempt)
- [ ] Response matches the profile schema
