# Task 004-1 — Add python-json-logger Dependency

## Parent User Story

[US-004 — Structured JSON Logging](../USER_STORIES/user_story_004.md)

## Description

Install the `python-json-logger` library and verify compatibility with the existing logging infrastructure.

## Work to be Done

1. Add `python-json-logger>=2.0.7` to `pyproject.toml`
2. Update `requirements.txt` via `uv pip compile`
3. Verify the package imports correctly: `from pythonjsonlogger import jsonlogger`
4. Verify no conflicts with existing Flask logging setup
5. Add a `LOG_FORMAT` configuration variable to `config/default.py` (values: `"json"` or `"text"`)

## Expected Outcome

- `python-json-logger` is installed and importable
- Configuration variable allows toggling between JSON and text log formats

## Priority

**High**

## Acceptance Criteria

- [ ] `python-json-logger` is listed in `pyproject.toml` and `requirements.txt`
- [ ] Package imports without errors
- [ ] `LOG_FORMAT` config variable is available with default value `"text"`
- [ ] No existing tests are broken
