# Task 013-3 — Include Correlation ID in Error Responses

## Parent User Story

[US-013 — Request Correlation ID Tracking](../USER_STORIES/user_story_013.md)

## Description

Include the correlation ID in all error response bodies so that API consumers can reference it when reporting issues.

## Work to be Done

1. Update error handlers in `core/__init__.py` (or wherever error handlers are registered):
   - Add `correlation_id` field to all error response JSON bodies
   - Apply to 400, 401, 403, 404, 405, 422, 429, 500 handlers
2. Update the generic error response format:
   ```json
   {
     "error": "...",
     "message": "...",
     "correlation_id": "abc-123-def"
   }
   ```
3. Update custom error classes to include correlation ID

## Expected Outcome

- API consumers can reference correlation IDs when reporting errors
- Error responses include correlation ID for debugging

## Priority

**Low**

## Acceptance Criteria

- [ ] All error responses (4xx, 5xx) include `correlation_id` field
- [ ] Correlation ID in error response matches the response header
- [ ] Custom error classes support correlation ID injection
