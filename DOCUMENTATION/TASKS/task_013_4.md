# Task 013-4 — Forward Correlation ID to External Service Calls

## Parent User Story

[US-013 — Request Correlation ID Tracking](../USER_STORIES/user_story_013.md)

## Description

Include the correlation ID in outbound HTTP requests to external services (e.g., password scoring API) for distributed tracing.

## Work to be Done

1. Update external API calls in the codebase:
   - In `core/services/validators/passwords.py` (password scoring API call)
   - In any other outbound HTTP calls (e.g., email service)
2. Add `X-Correlation-ID` header to all outbound request headers:
   ```python
   headers["X-Correlation-ID"] = g.correlation_id
   ```
3. Create a utility function or requests session wrapper that auto-injects the header
4. Log outbound requests with the correlation ID

## Expected Outcome

- Correlation ID flows to external services
- External API calls are traceable back to the originating request

## Priority

**Low**

## Acceptance Criteria

- [ ] Outbound HTTP requests include `X-Correlation-ID` header
- [ ] Correlation ID matches the value from the incoming request
- [ ] A utility/wrapper simplifies header injection
- [ ] Outbound request logs include the correlation ID
