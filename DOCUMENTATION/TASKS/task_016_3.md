# Task 016-3 — Create Database Restore Script

## Parent User Story

[US-016 — Automated Database Backup Strategy](../USER_STORIES/user_story_016.md)

## Description

Create a script to restore the database from a backup file, with safety checks and validation.

## Work to be Done

1. Create `scripts/db_restore.sh`:
   - Accept parameters: backup file path, target database name
   - Validate the backup file exists and is a valid pg_dump format
   - Prompt for confirmation before restoring (with --force to skip)
   - Use `pg_restore` to restore: `pg_restore -d <db> -c --if-exists`
   - Run Alembic migrations after restore to ensure schema is current
   - Verify the restoration by running a basic query
2. Add a `--dry-run` option to validate without restoring
3. Add logging for the restore process
4. Document the restore procedure

## Expected Outcome

- Databases can be restored from backup files reliably
- Safety checks prevent accidental data loss

## Priority

**Medium**

## Acceptance Criteria

- [ ] Script restores from a valid pg_dump backup
- [ ] Confirmation prompt prevents accidental restoration
- [ ] `--force` flag skips the confirmation
- [ ] `--dry-run` validates the backup without restoring
- [ ] Alembic migrations run after restore
- [ ] Post-restore verification passes
