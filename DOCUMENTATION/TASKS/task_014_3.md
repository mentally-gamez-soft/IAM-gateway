# Task 014-3 — Create POST /2fa/verify Endpoint

## Parent User Story

[US-014 — Two-Factor Authentication (2FA)](../USER_STORIES/user_story_014.md)

## Description

Create an endpoint to verify a TOTP code during 2FA setup, confirming the user has correctly configured their authenticator app.

## Work to be Done

1. In `core/users/routes/two_factor.py`, implement `POST /2fa/verify`:
   - Require authentication
   - Accept JSON body: `{"code": "123456"}`
   - Validate the TOTP code against the stored secret:
     ```python
     totp = pyotp.TOTP(user.totp_secret)
     is_valid = totp.verify(code, valid_window=1)
     ```
   - If valid:
     - Set `is_2fa_enabled = True` and `two_fa_enabled_at`
     - Generate recovery codes
     - Return recovery codes (one-time display)
   - If invalid, return error

## Expected Outcome

- 2FA is enabled after successful verification
- Recovery codes are provided for backup access

## Priority

**High**

## Acceptance Criteria

- [ ] Valid TOTP code activates 2FA on the account
- [ ] Recovery codes are returned upon activation
- [ ] Invalid TOTP code returns error without activating 2FA
- [ ] `is_2fa_enabled` flag is set to `True`
- [ ] Endpoint is idempotent if already enabled
