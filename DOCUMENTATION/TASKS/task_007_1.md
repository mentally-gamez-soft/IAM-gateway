# Task 007-1 — Add Connection Pool Configuration to Environment Configs

## Parent User Story

[US-007 — Database Connection Pooling and Health Monitoring](../USER_STORIES/user_story_007.md)

## Description

Define database connection pool configuration variables in each environment config file with appropriate values per environment.

## Work to be Done

1. Add the following variables to `config/default.py`:
   - `SQLALCHEMY_POOL_SIZE` (default: 5)
   - `SQLALCHEMY_MAX_OVERFLOW` (default: 10)
   - `SQLALCHEMY_POOL_RECYCLE` (default: 1800 — 30 minutes)
   - `SQLALCHEMY_POOL_PRE_PING` (default: True)
   - `SQLALCHEMY_POOL_TIMEOUT` (default: 30 seconds)
2. Override per environment:
   - `config/local.py`: pool_size=3, max_overflow=5
   - `config/testing.py`: pool_size=2, max_overflow=3
   - `config/dev.py`: pool_size=5, max_overflow=10
   - `config/staging.py`: pool_size=10, max_overflow=15
   - `config/prod.py`: pool_size=15, max_overflow=25
3. Add variables to `.env` template files
4. Add to `validate_config.py` if needed

## Expected Outcome

- Pool sizes scale appropriately per environment
- Configuration is externalized and documented

## Priority

**Medium**

## Acceptance Criteria

- [ ] Pool configuration variables are defined in `config/default.py`
- [ ] Each environment has appropriately sized pool settings
- [ ] Variables are sourced from environment/.env files
- [ ] Documentation comments explain the purpose of each setting
