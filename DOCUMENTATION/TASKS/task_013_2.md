# Task 013-2 — Inject Correlation ID into Log Records

## Parent User Story

[US-013 — Request Correlation ID Tracking](../USER_STORIES/user_story_013.md)

## Description

Ensure the correlation ID is included in every log entry for the duration of the request so that logs can be traced across a single request.

## Work to be Done

1. Create or update a logging filter in `server/config/logs.py`:
   ```python
   class CorrelationIdFilter(logging.Filter):
       def filter(self, record):
           record.correlation_id = getattr(g, 'correlation_id', 'N/A')
           return True
   ```
2. Add the filter to all application loggers
3. Update the log format to include `[%(correlation_id)s]`
4. For JSON logging (US-004), add `correlation_id` as a structured field
5. Ensure the filter handles requests outside of Flask context (e.g., background tasks)

## Expected Outcome

- All log entries include the request's correlation ID
- Log searches can filter by correlation ID

## Priority

**Medium**

## Acceptance Criteria

- [ ] Every log line within a request includes the correlation ID
- [ ] Log format includes the correlation ID field
- [ ] Logs outside request context show `N/A` or a default value
- [ ] JSON logs include `correlation_id` as a top-level field (if US-004 is implemented)
