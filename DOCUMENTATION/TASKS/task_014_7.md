# Task 014-7 — Write Tests for 2FA Lifecycle

## Parent User Story

[US-014 — Two-Factor Authentication (2FA)](../USER_STORIES/user_story_014.md)

## Description

Write comprehensive tests for the full 2FA lifecycle: enable, verify, login, disable, and recovery codes.

## Work to be Done

1. Create `tests/test_two_factor.py` with test cases:
   - **Setup**:
     - POST /2fa/enable returns provisioning URI
     - POST /2fa/verify with valid code enables 2FA
     - POST /2fa/verify with invalid code fails
   - **Login**:
     - Login with 2FA enabled but no code returns 202
     - Login with valid TOTP code succeeds
     - Login with invalid TOTP code fails
     - Login with valid recovery code succeeds
     - Used recovery code cannot be reused
   - **Disable**:
     - POST /2fa/disable with valid password succeeds
     - POST /2fa/disable with invalid password fails
   - **Recovery**:
     - POST /2fa/recovery-codes/regenerate returns new codes
     - Old recovery codes are invalidated after regeneration
   - **Edge Cases**:
     - Non-2FA user login is unaffected
     - Double enable returns appropriate error
2. Use `pyotp` to generate valid TOTP codes in tests

## Expected Outcome

- Full 2FA lifecycle is covered by automated tests
- Edge cases and security scenarios are validated

## Priority

**High**

## Acceptance Criteria

- [ ] At least 13 test cases covering all 2FA scenarios
- [ ] Setup, login, disable, and recovery flows tested
- [ ] Security edge cases validated (reuse, invalid codes)
- [ ] All tests pass in CI
