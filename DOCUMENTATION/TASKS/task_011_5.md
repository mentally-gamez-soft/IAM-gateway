# Task 011-5 — Write Tests for Profile Endpoints

## Parent User Story

[US-011 — User Profile Management](../USER_STORIES/user_story_011.md)

## Description

Write comprehensive tests for the GET and PUT profile endpoints.

## Work to be Done

1. Create `tests/test_profile.py` with test cases:
   - GET profile returns 200 with profile data for authenticated user
   - GET profile returns 401 for unauthenticated user
   - PUT profile updates display_name successfully
   - PUT profile updates multiple fields at once
   - PUT profile rejects invalid language_preference
   - PUT profile rejects attempt to update email
   - PUT profile rejects attempt to update username
   - PUT profile returns 401 for unauthenticated user
   - PUT profile with empty body returns current profile or 422
   - profile_updated_at is set after PUT
2. Use existing test infrastructure (base test class, helpers)

## Expected Outcome

- Profile endpoints are fully covered by tests
- Edge cases are validated

## Priority

**Medium**

## Acceptance Criteria

- [ ] At least 10 test cases covering both endpoints
- [ ] Authentication enforcement is validated
- [ ] Field validation is tested (valid and invalid inputs)
- [ ] Protected field rejection is tested
- [ ] All tests pass in CI
