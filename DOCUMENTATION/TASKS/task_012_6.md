# Task 012-6 — Write Tests for GDPR Endpoints

## Parent User Story

[US-012 — GDPR Compliance Endpoints](../USER_STORIES/user_story_012.md)

## Description

Write comprehensive tests for all GDPR endpoints including data export, account deletion, and consent management.

## Work to be Done

1. Create `tests/test_gdpr.py` with test cases:
   - **Data Export**:
     - GET /user/data returns complete user data
     - GET /user/data returns 401 for unauthenticated
     - Export contains all expected fields
   - **Account Deletion**:
     - DELETE /user/account with correct password succeeds
     - DELETE /user/account without confirmation fails
     - DELETE /user/account with wrong password fails
     - Deleted user cannot log in
     - Deleted user's tokens are invalidated
   - **Consent Management**:
     - GET /user/consent returns all consent types
     - PUT /user/consent updates preferences
     - Consent changes are timestamped
   - **Edge Cases**:
     - Double deletion attempt
     - Data export after deletion attempt

## Expected Outcome

- GDPR endpoints are fully covered by tests
- Account deletion lifecycle is validated end-to-end

## Priority

**Medium**

## Acceptance Criteria

- [ ] At least 12 test cases covering all GDPR endpoints
- [ ] Account deletion lifecycle tested (delete → login denied → token rejected)
- [ ] Consent tracking validated (timestamps, IP address)
- [ ] All tests pass in CI
