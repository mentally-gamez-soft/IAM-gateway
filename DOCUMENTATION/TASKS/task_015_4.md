# Task 015-4 — Add Celery Worker to Docker Compose

## Parent User Story

[US-015 — Asynchronous Email Delivery](../USER_STORIES/user_story_015.md)

## Description

Add a Celery worker service to the Docker Compose files for both dev and prod environments.

## Work to be Done

1. Update `Docker/application/dev/docker-compose-dev.yaml`:
   ```yaml
   celery-worker:
     build: ../../../
     command: celery -A core.tasks worker --loglevel=info --concurrency=2
     environment:
       - CELERY_BROKER_URL=redis://redis:6379/1
     depends_on:
       - redis
   ```
2. Update `Docker/application/prod/docker-compose-prod.yaml` with a production-ready worker configuration
3. Add a Redis service if not already present (from US-001)
4. Add health checks for the Celery worker
5. Configure resource limits for the worker container
6. Add Celery Flower (monitoring dashboard) as an optional service

## Expected Outcome

- Celery worker runs alongside the application in Docker
- Worker processes email tasks from the Redis queue

## Priority

**Medium**

## Acceptance Criteria

- [x] Celery worker service is defined in both dev and prod compose files
- [x] Worker connects to Redis and processes tasks
- [x] Worker restarts on failure (`restart: unless-stopped`)
- [x] Resource limits are configured for production (CPU 0.50 / RAM 256 M)
- [x] `docker compose up` starts the worker automatically
