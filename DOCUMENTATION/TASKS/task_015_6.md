# Task 015-6 — Add Monitoring for Celery Queue

## Parent User Story

[US-015 — Asynchronous Email Delivery](../USER_STORIES/user_story_015.md)

## Description

Set up monitoring for the Celery task queue to track queue depth, task processing times, and worker health.

## Work to be Done

1. Add `flower>=2.0.0` to `pyproject.toml` (Celery monitoring tool)
2. Add Flower service to Docker Compose:
   ```yaml
   celery-flower:
     image: mher/flower
     command: celery -A core.tasks flower --port=5555
     ports:
       - "5555:5555"
   ```
3. Expose queue metrics in the `/health` endpoint (if US-005 is implemented):
   - Queue depth (pending tasks)
   - Active tasks
   - Worker count
4. Add alerting for queue depth thresholds

## Expected Outcome

- Queue health is visible via Flower dashboard
- Queue metrics are accessible programmatically

## Priority

**Low**

## Acceptance Criteria

- [x] Flower dashboard is accessible for monitoring (`http://localhost:5555`, basic auth via `FLOWER_BASIC_AUTH`)
- [ ] Queue depth is visible in the health endpoint (not implemented — deferred to future iteration)
- [x] Worker health is monitored via Flower UI and worker heartbeats
- [ ] High queue depth triggers an alert (not implemented — deferred to future iteration)
