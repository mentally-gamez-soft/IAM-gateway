# Task 009-3 — Write Tests for CORS Headers in Responses

## Parent User Story

[US-009 — CORS Configuration](../USER_STORIES/user_story_009.md)

## Description

Write tests verifying that CORS headers are correctly included in API responses and that preflight requests are handled.

## Work to be Done

1. Create `tests/test_cors.py` with test cases:
   - GET request includes `Access-Control-Allow-Origin` header
   - OPTIONS preflight request returns correct CORS headers
   - `Access-Control-Allow-Methods` includes expected methods
   - `Access-Control-Allow-Headers` includes expected headers
   - `Access-Control-Expose-Headers` includes `X-CSRFToken`
   - `Access-Control-Allow-Credentials` is `true`
   - `Access-Control-Max-Age` is set correctly
2. Test with allowed and disallowed origin values
3. Verify CORS headers on error responses (4xx, 5xx)

## Expected Outcome

- CORS headers are validated by automated tests
- Both success and error responses include CORS headers

## Priority

**Low**

## Acceptance Criteria

- [ ] At least 7 test cases covering the scenarios above
- [ ] CORS headers are present on both success and error responses
- [ ] Preflight handling is validated
- [ ] All tests pass in CI
