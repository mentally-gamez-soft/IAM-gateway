# Task 019-2 — Create `.coveragerc` Configuration File

## Parent User Story

[US-019 — Test Coverage Measurement](../USER_STORIES/user_story_019.md)

## Description

Create a `.coveragerc` file at the project root that configures the `coverage` library for the IAM Gateway test suite.

## Work to be Done

1. Create `.coveragerc` at the repository root with the following sections:
   - `[run]`: set `source` to `core,config,server`; enable `branch = True`; set `omit` patterns to exclude `*/tests/*`, `*/migrations/*`, `*/.venv/*`, `*/Docker/*`
   - `[report]`: configure `show_missing = True`; set `exclude_lines` for common non-executable patterns (`pragma: no cover`, `if TYPE_CHECKING`, `raise NotImplementedError`, `pass`)
   - `[html]`: set `directory = htmlcov`

## Expected Outcome

Running `coverage run -m unittest discover -s tests` followed by `coverage report` produces a console table showing coverage percentages per file, and `coverage html` produces an HTML report in `htmlcov/`.

## Priority

**Medium**

## Acceptance Criteria

- [ ] `.coveragerc` exists at project root
- [ ] `coverage run -m unittest discover -s tests` completes without errors
- [ ] `coverage report` shows per-file coverage percentages
- [ ] `coverage html` generates `htmlcov/index.html`
- [ ] Branch coverage is enabled
