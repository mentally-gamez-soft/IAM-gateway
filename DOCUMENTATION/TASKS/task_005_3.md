# Task 005-3 — Configure CSRF Exemption for Health Routes

## Parent User Story

[US-005 — Health Check and Readiness Probes](../USER_STORIES/user_story_005.md)

## Description

Ensure the `/health` and `/ready` endpoints are exempt from CSRF protection so that monitoring tools and container orchestrators can call them without tokens.

## Work to be Done

1. In `core/__init__.py`, after initializing `CSRFProtect`, add CSRF exemptions:
   - `csrf.exempt()` for the health check view functions
   - Or use `@csrf.exempt` decorator on the health routes
2. Verify that the exemption works for both `GET /health` and `GET /ready`
3. Ensure no other routes are accidentally exempted
4. Document the exemption rationale in code comments

## Expected Outcome

- Health endpoints are callable without CSRF tokens
- No other endpoints are affected by the exemption

## Priority

**Medium**

## Acceptance Criteria

- [ ] `GET /health` is callable without a CSRF token
- [ ] `GET /ready` is callable without a CSRF token
- [ ] All other endpoints still require CSRF tokens (when CSRF is enabled)
- [ ] No security regression introduced by the exemption
