# Task 011-4 — Add Swagger Documentation for Profile Endpoints

## Parent User Story

[US-011 — User Profile Management](../USER_STORIES/user_story_011.md)

## Description

Document the profile endpoints in the Swagger/OpenAPI specification.

## Work to be Done

1. Add profile endpoint entries to `static/swagger-docs/swagger.json` (or schema decorators if US-010 is complete):
   - `GET /profile`: response schema with all profile fields
   - `PUT /profile`: request body schema + response schema
2. Add authentication requirement documentation (JWT Bearer)
3. Include example requests and responses
4. Add error response documentation (401, 403, 422)

## Expected Outcome

- Profile endpoints are documented in Swagger
- API consumers can understand the profile API from the docs

## Priority

**Low**

## Acceptance Criteria

- [ ] Both GET and PUT profile endpoints appear in Swagger
- [ ] Request/response schemas are complete
- [ ] Authentication requirements are documented
- [ ] Error responses are documented
