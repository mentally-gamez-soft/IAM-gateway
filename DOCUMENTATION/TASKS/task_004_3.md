# Task 004-3 — Add Request Context Fields to Log Records

## Parent User Story

[US-004 — Structured JSON Logging](../USER_STORIES/user_story_004.md)

## Description

Implement a logging filter that enriches log records with request-scoped context such as `request_id` and `user_id`.

## Work to be Done

1. Create a `RequestContextFilter` class (logging.Filter) in `server/config/logs.py`
2. In the `filter()` method, add the following to the log record:
   - `request_id`: from Flask `g.request_id` (or generate one if not set)
   - `user_id`: from `flask_login.current_user.id` (or `None` if anonymous)
   - `remote_addr`: from `flask.request.remote_addr`
   - `method`: from `flask.request.method`
   - `path`: from `flask.request.path`
3. Handle `RuntimeError` for out-of-context logging (e.g., during app startup)
4. Attach the filter to all handlers in `configure_logging()`

## Expected Outcome

- Every log line within a request context includes request ID, user ID, and request metadata
- Logs outside of request context gracefully omit these fields

## Priority

**High**

## Acceptance Criteria

- [ ] Log records include `request_id` when inside a Flask request context
- [ ] Log records include `user_id` when a user is authenticated
- [ ] Log records outside of request context do not cause errors
- [ ] Filter is attached to all configured handlers
- [ ] Log output demonstrates enriched context fields
