# Task 011-1 — Create User Profile Model Fields

## Parent User Story

[US-011 — User Profile Management](../USER_STORIES/user_story_011.md)

## Description

Extend the `GwUser` model with profile fields such as display name, avatar URL, bio, and preferences.

## Work to be Done

1. Add fields to `core/users/models.py` (`GwUser`):
   - `display_name` — `db.Column(db.String(80), nullable=True)`
   - `avatar_url` — `db.Column(db.String(255), nullable=True)`
   - `bio` — `db.Column(db.Text, nullable=True)`
   - `language_preference` — `db.Column(db.String(5), default="en")`
   - `timezone` — `db.Column(db.String(50), default="UTC")`
   - `profile_updated_at` — `db.Column(db.DateTime, nullable=True)`
2. Create an Alembic migration for the new columns
3. Set default values for existing users
4. Add `to_profile_dict()` method on the model for serialized profile output

## Expected Outcome

- `GwUser` model supports profile information
- Migration adds columns safely to existing database
- Profile data is serializable

## Priority

**Medium**

## Acceptance Criteria

- [ ] New columns are added to `GwUser` model
- [ ] Alembic migration runs successfully (upgrade and downgrade)
- [ ] `to_profile_dict()` returns a JSON-serializable dictionary
- [ ] Existing users are not broken by the migration
- [ ] Default values are set for new fields
