# Task 008-3 — Validate Permissions on Logs and Upload Directories

## Parent User Story

[US-008 — Dockerize with Non-Root User](../USER_STORIES/user_story_008.md)

## Description

Verify that all application-writable directories (logs, uploads, media) have correct permissions for the non-root user.

## Work to be Done

1. Audit all directories the application writes to:
   - `logs/` — log file output
   - `media/uploads/` — file uploads (if used)
   - `instance/` — Flask instance folder
2. Update the Dockerfile to create these directories with correct ownership:
   ```dockerfile
   RUN mkdir -p ./logs ./media/uploads ./instance && \
       chown -R appuser:appgroup ./logs ./media ./instance
   ```
3. Test file writing operations under the non-root user:
   - Log file creation and rotation
   - File upload (if applicable)
4. Verify SQLite (if used in testing) is writable

## Expected Outcome

- All writable directories are owned by the non-root user
- No file permission errors during normal operation

## Priority

**Medium**

## Acceptance Criteria

- [ ] All writable directories exist with correct ownership in the container
- [ ] Log files are created successfully during application runtime
- [ ] File uploads work without permission errors (if applicable)
- [ ] No `PermissionError` or `IOError` during normal operation
