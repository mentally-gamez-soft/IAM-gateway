# Task 017-4 — Write Integration Tests for Role-Based Access Control

## Parent User Story

[US-017 — Integration and End-to-End Test Suite](../USER_STORIES/user_story_017.md)

## Description

Write integration tests verifying that role-based access control (RBAC) correctly restricts endpoint access.

## Work to be Done

1. Create `tests/integration/test_rbac.py`:
   - Admin user can assign roles
   - Non-admin user cannot assign roles (403)
   - Role-protected endpoints reject unauthorized users
   - Multiple roles can be assigned to a user
   - Role removal revokes access
   - Sanity check endpoint is accessible to authenticated users
   - Role assignment with invalid role name fails
   - Unauthenticated user cannot access role endpoints
2. Use UserFactory with different role configurations
3. Test the authorization_guard decorator behavior

## Expected Outcome

- RBAC is validated through integration tests
- Permission boundaries are verified

## Priority

**Medium**

## Acceptance Criteria

- [ ] At least 8 test cases covering RBAC scenarios
- [ ] Admin and non-admin access patterns tested
- [ ] Role assignment and removal tested
- [ ] Authorization guard behavior validated
- [ ] All tests pass in CI
