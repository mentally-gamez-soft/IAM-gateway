# Task 017-5 — Write Security-Focused Tests

## Parent User Story

[US-017 — Integration and End-to-End Test Suite](../USER_STORIES/user_story_017.md)

## Description

Write tests specifically targeting security controls: CSRF protection, payload encryption, input validation, and common attack vectors.

## Work to be Done

1. Create `tests/security/test_csrf.py`:
   - POST requests without CSRF token are rejected (out of testing mode)
   - CSRF token in response can be used in subsequent requests
   - Cross-origin CSRF attempts are blocked
2. Create `tests/security/test_input_validation.py`:
   - SQL injection attempts are sanitized
   - XSS payloads in fields are sanitized or rejected
   - Oversized payloads are rejected
   - Special characters in username/email are handled
3. Create `tests/security/test_jwt_security.py`:
   - JWT signed with wrong key is rejected
   - JWT with modified payload is rejected
   - JWT with future `iat` claim is handled
   - JWT without required claims is rejected
4. Create `tests/security/test_payload_encryption.py`:
   - Encrypted payloads decrypt correctly
   - Tampered payloads are rejected

## Expected Outcome

- Security controls are validated by automated tests
- Common attack vectors are tested

## Priority

**High**

## Acceptance Criteria

- [ ] At least 12 test cases across all security categories
- [ ] CSRF protection is validated
- [ ] JWT security is validated
- [ ] Input validation is tested against common attack payloads
- [ ] All tests pass in CI
