# Task 014-6 — Create POST /2fa/recovery-codes/regenerate Endpoint

## Parent User Story

[US-014 — Two-Factor Authentication (2FA)](../USER_STORIES/user_story_014.md)

## Description

Create an endpoint that allows users to regenerate their 2FA recovery codes.

## Work to be Done

1. In `core/users/routes/two_factor.py`, implement `POST /2fa/recovery-codes/regenerate`:
   - Require authentication
   - Require TOTP code or password confirmation
   - Generate new set of 8 recovery codes
   - Replace existing recovery codes in the database
   - Return the new recovery codes (one-time display)
2. Log the regeneration event
3. Invalidate all previous recovery codes

## Expected Outcome

- Users can regenerate recovery codes if they lose them
- Old recovery codes are invalidated

## Priority

**Low**

## Acceptance Criteria

- [ ] New recovery codes are generated and returned
- [ ] Old recovery codes are invalidated
- [ ] Authentication and TOTP/password verification required
- [ ] Event is logged for audit
- [ ] Recovery codes are shown only once in the response
