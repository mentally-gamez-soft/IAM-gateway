# Task 017-1 — Set Up Pytest, Factory Boy, and Test Database Config

## Parent User Story

[US-017 — Integration and End-to-End Test Suite](../USER_STORIES/user_story_017.md)

## Description

Configure the test infrastructure with pytest, Factory Boy for test data generation, and a dedicated test database.

## Work to be Done

1. Add to `pyproject.toml`:
   - `pytest>=8.0.0`
   - `pytest-cov>=5.0.0`
   - `pytest-flask>=1.3.0`
   - `factory-boy>=3.3.0`
   - `faker>=22.0.0`
2. Update `requirements.txt`
3. Create `tests/conftest.py` with:
   - Flask app fixture using testing configuration
   - Database setup/teardown per test (or per session)
   - Test client fixture
   - Authenticated client fixture (pre-logged-in)
   - Database transaction rollback after each test
4. Create `tests/factories.py` with Factory Boy factories:
   - `UserFactory` — creates `GwUser` instances with realistic fake data
   - `RoleFactory` — if applicable
5. Verify the testing configuration uses a separate database schema
6. Configure `pyproject.toml` `[tool.pytest.ini_options]` section

## Expected Outcome

- Test infrastructure is ready for writing integration tests
- Test data can be generated consistently via factories

## Priority

**High**

## Acceptance Criteria

- [ ] `pytest` runs without configuration errors
- [ ] Flask app fixture provides a test client
- [ ] Database is cleaned between tests
- [ ] `UserFactory` generates valid test users
- [ ] Test configuration uses a separate database/schema
- [ ] `pytest-cov` generates coverage reports
