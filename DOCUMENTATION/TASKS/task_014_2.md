# Task 014-2 — Create POST /2fa/enable Endpoint

## Parent User Story

[US-014 — Two-Factor Authentication (2FA)](../USER_STORIES/user_story_014.md)

## Description

Create an authenticated endpoint that initiates 2FA setup by generating a TOTP secret and returning the QR code provisioning URI.

## Work to be Done

1. Create `core/users/routes/two_factor.py`
2. Implement `POST /2fa/enable`:
   - Require authentication via `@login_required` and `authorization_guard`
   - Generate a new TOTP secret using `pyotp.random_base32()`
   - Store the secret temporarily (not yet confirmed) or in a pending state
   - Return the provisioning URI for QR code generation:
     ```python
     totp = pyotp.TOTP(secret)
     uri = totp.provisioning_uri(user.email, issuer_name="IAM-Gateway")
     ```
   - Return the URI (and optionally a QR code image as base64)
3. Do NOT enable 2FA yet — require verification via `/2fa/verify`
4. Register the route in the users blueprint

## Expected Outcome

- Users can initiate 2FA setup and scan a QR code
- 2FA is not active until verified

## Priority

**High**

## Acceptance Criteria

- [ ] `POST /2fa/enable` returns a TOTP provisioning URI
- [ ] Secret is generated but 2FA is not yet active
- [ ] Unauthenticated requests return 401
- [ ] Already-enabled 2FA returns appropriate error
- [ ] CSRF token is required
