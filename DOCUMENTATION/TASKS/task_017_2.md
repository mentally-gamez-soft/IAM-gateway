# Task 017-2 — Write Integration Tests for User Registration Flow

## Parent User Story

[US-017 — Integration and End-to-End Test Suite](../USER_STORIES/user_story_017.md)

## Description

Write integration tests covering the complete user registration flow from signup through email activation.

## Work to be Done

1. Create `tests/integration/test_registration.py`:
   - Valid signup creates user and returns success
   - Signup with duplicate email returns error
   - Signup with duplicate username returns error
   - Signup with weak password returns error (if password scoring is configured)
   - Signup with missing fields returns validation error
   - Email activation with valid token activates user
   - Email activation with expired token fails
   - Email activation with invalid token fails
   - Activated user can log in
   - Non-activated user cannot log in (if enforced)
2. Use the test client and factories from conftest.py
3. Mock external services (e.g., password scoring API)

## Expected Outcome

- Registration flow is fully validated end-to-end
- Edge cases and error conditions are covered

## Priority

**High**

## Acceptance Criteria

- [ ] At least 10 test cases covering the registration flow
- [ ] Happy path: signup → activate → login
- [ ] Error cases: duplicate email, duplicate username, weak password
- [ ] Token validation: valid, expired, invalid
- [ ] All tests pass in CI
