# Task 016-5 — Write Tests and Validation for Backup/Restore

## Parent User Story

[US-016 — Automated Database Backup Strategy](../USER_STORIES/user_story_016.md)

## Description

Write tests and validation scripts to ensure backup and restore processes work correctly.

## Work to be Done

1. Create `tests/test_backup_restore.sh` (shell-based integration test):
   - Create a test database with sample data
   - Run the backup script
   - Verify the backup file exists and is non-empty
   - Drop and recreate the test database
   - Run the restore script
   - Verify the data was restored correctly
2. Add backup validation to the backup script:
   - Verify backup size is within expected range
   - Validate with `pg_restore --list` (list contents without restoring)
3. Create a CI step that tests backup/restore in the pipeline
4. Document the test procedure

## Expected Outcome

- Backup/restore pipeline is validated by automated tests
- Backup integrity is verified after each backup

## Priority

**Low**

## Acceptance Criteria

- [ ] Integration test validates the full backup → restore cycle
- [ ] Backup file integrity is verified
- [ ] Data is confirmed present after restore
- [ ] Tests can run in CI
- [ ] Test procedure is documented
