# Task 005-5 — Write Tests for Health Endpoints

## Parent User Story

[US-005 — Health Check and Readiness Probes](../USER_STORIES/user_story_005.md)

## Description

Create tests for the `/health` and `/ready` endpoints covering both healthy and unhealthy scenarios.

## Work to be Done

1. Create `tests/test_health.py` with test cases:
   - `GET /health` returns 200 with correct JSON schema
   - `GET /health` response includes `status`, `timestamp`, `version`
   - `GET /health` does not require authentication
   - `GET /ready` returns 200 when all dependencies are available
   - `GET /ready` returns 503 when database is unavailable (mock database failure)
   - `GET /ready` includes individual check results in response
   - `GET /ready` does not require authentication
   - Health endpoints respond within timeout limits
2. Mock external dependencies (database, SMTP) for failure scenarios
3. Verify CSRF exemption works

## Expected Outcome

- Health endpoints are fully tested
- Both success and failure scenarios are covered

## Priority

**Medium**

## Acceptance Criteria

- [ ] At least 8 test cases covering the scenarios above
- [ ] Database failure scenario is tested via mocking
- [ ] CSRF exemption is verified in tests
- [ ] Response schemas are validated
- [ ] All tests pass in CI
