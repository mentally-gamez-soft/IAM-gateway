# Task 015-1 — Install and Configure Celery with Redis Broker

## Parent User Story

[US-015 — Asynchronous Email Delivery](../USER_STORIES/user_story_015.md)

## Description

Install Celery and configure it with Redis as the message broker for background task processing.

## Work to be Done

1. Add to `pyproject.toml`:
   - `celery>=5.3.0`
   - `redis>=5.0.0` (if not already added from US-001)
2. Update `requirements.txt`
3. Create `core/tasks/__init__.py` with Celery app initialization:
   ```python
   from celery import Celery
   
   celery_app = Celery("iam_gateway")
   ```
4. Add Celery configuration to `config/default.py`:
   - `CELERY_BROKER_URL` — Redis URL
   - `CELERY_RESULT_BACKEND` — Redis URL
   - `CELERY_TASK_SERIALIZER` — "json"
   - `CELERY_ACCEPT_CONTENT` — ["json"]
   - `CELERY_TASK_TRACK_STARTED` — True
   - `CELERY_TASK_TIME_LIMIT` — 300
5. Add environment-specific Celery URLs
6. Configure Celery to work with Flask application context

## Expected Outcome

- Celery is installed and configured with Redis broker
- Celery app is initialized and integrated with Flask

## Priority

**Medium**

## Acceptance Criteria

- [x] Celery is installed and importable
- [x] Celery connects to Redis broker
- [x] Configuration is sourced from environment settings
- [x] Celery app works within Flask application context
- [x] Worker can be started with `celery -A application.celery worker` (module-level `celery` also accessible via `core.tasks`)
