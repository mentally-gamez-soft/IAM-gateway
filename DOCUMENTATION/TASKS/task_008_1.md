# Task 008-1 — Update Application Dockerfile for Non-Root Execution

## Parent User Story

[US-008 — Dockerize with Non-Root User](../USER_STORIES/user_story_008.md)

## Description

Modify the application `Dockerfile` to create a non-root user and run the application process under that user.

## Work to be Done

1. In the final stage of the `Dockerfile`, add user creation:
   ```dockerfile
   RUN addgroup -S appgroup && adduser -S appuser -G appgroup -u 1000
   ```
2. Set ownership of `/app` directory: `RUN chown -R appuser:appgroup /app`
3. Ensure the `logs/` directory is writable: `RUN mkdir -p ./logs && chown appuser:appgroup ./logs`
4. Switch to the non-root user: `USER appuser`
5. Place `USER appuser` after all `COPY` and `RUN` commands that require root
6. Verify the application starts correctly under the non-root user
7. Update `LABEL` and metadata in the Dockerfile

## Expected Outcome

- The container process runs as `appuser` (UID 1000), not root
- All required directories are writable by the non-root user
- No functional changes to the application

## Priority

**High**

## Acceptance Criteria

- [ ] `docker exec <container> whoami` returns `appuser`
- [ ] Application starts and serves requests correctly
- [ ] Logs are writable at `/app/logs/`
- [ ] No file permission errors during runtime
- [ ] Container image builds successfully
