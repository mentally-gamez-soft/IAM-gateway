# Task 005-4 — Add Docker Healthcheck Directives

## Parent User Story

[US-005 — Health Check and Readiness Probes](../USER_STORIES/user_story_005.md)

## Description

Add Docker `HEALTHCHECK` directives to the Docker Compose configurations so that Docker monitors the application health automatically.

## Work to be Done

1. Add `healthcheck` to the application service in `Docker/application/dev/docker-compose-dev.yaml`:
   ```yaml
   healthcheck:
     test: ["CMD", "curl", "-f", "http://localhost:5000/health"]
     interval: 30s
     timeout: 5s
     retries: 3
     start_period: 10s
   ```
2. Add similar `healthcheck` to `Docker/application/prod/docker-compose-prod.yaml` (using the Gunicorn port)
3. Add `healthcheck` to the Nginx service using the `/health` endpoint on port 80
4. Ensure `curl` is available in the Docker images (or use `wget` for Alpine)
5. Optionally add `HEALTHCHECK` to the `Dockerfile` itself

## Expected Outcome

- Docker automatically monitors container health via the `/health` endpoint
- Unhealthy containers are visible via `docker ps` and `docker inspect`

## Priority

**Medium**

## Acceptance Criteria

- [ ] `docker ps` shows health status for application containers
- [ ] Container marked `unhealthy` when the `/health` endpoint fails
- [ ] Health check interval and retries are configured appropriately
- [ ] `curl` or `wget` is available in the container image for health checks
