# Task 016-2 — Implement Backup Retention Policy

## Parent User Story

[US-016 — Automated Database Backup Strategy](../USER_STORIES/user_story_016.md)

## Description

Add a retention policy to the backup script that manages backup lifecycle: daily, weekly, and monthly retention.

## Work to be Done

1. Update `scripts/db_backup.sh` to support retention:
   - Keep daily backups for 7 days
   - Keep weekly backups (Sundays) for 4 weeks
   - Keep monthly backups (1st of month) for 12 months
2. Add a cleanup function that removes expired backups:
   ```bash
   find "$BACKUP_DIR" -name "*.dump" -mtime +7 -not -name "*weekly*" -not -name "*monthly*" -delete
   ```
3. Tag backup files by type: `daily_`, `weekly_`, `monthly_` prefix
4. Log cleanup actions (files removed, space freed)
5. Add a `--dry-run` flag to preview deletions without executing

## Expected Outcome

- Backup storage grows at a sustainable rate
- Old backups are automatically cleaned up
- Critical backups (weekly, monthly) are retained longer

## Priority

**Medium**

## Acceptance Criteria

- [ ] Daily backups older than 7 days are removed
- [ ] Weekly backups are retained for 4 weeks
- [ ] Monthly backups are retained for 12 months
- [ ] Cleanup actions are logged
- [ ] `--dry-run` shows what would be deleted without deleting
