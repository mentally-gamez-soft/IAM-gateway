# Task 013-5 — Write Tests for Correlation ID Tracking

## Parent User Story

[US-013 — Request Correlation ID Tracking](../USER_STORIES/user_story_013.md)

## Description

Write tests verifying the complete correlation ID lifecycle: generation, propagation, logging, and response headers.

## Work to be Done

1. Create `tests/test_correlation_id.py` with test cases:
   - Request without `X-Correlation-ID` gets one auto-generated
   - Request with `X-Correlation-ID` preserves the provided value
   - Response includes `X-Correlation-ID` header
   - Auto-generated correlation ID is a valid UUID4
   - Error responses include `correlation_id` in the body
   - Correlation ID appears in log output
2. Verify correlation ID consistency within a single request
3. Verify different requests get different correlation IDs

## Expected Outcome

- Correlation ID behavior is fully validated by tests

## Priority

**Low**

## Acceptance Criteria

- [ ] At least 7 test cases covering the scenarios above
- [ ] UUID4 format is validated for auto-generated IDs
- [ ] Correlation ID propagation is verified
- [ ] All tests pass in CI
