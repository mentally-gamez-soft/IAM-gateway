# Task 017-3 — Write Integration Tests for Authentication Flow

## Parent User Story

[US-017 — Integration and End-to-End Test Suite](../USER_STORIES/user_story_017.md)

## Description

Write integration tests covering the login, session management, and logout flow.

## Work to be Done

1. Create `tests/integration/test_authentication.py`:
   - Valid login returns JWT token
   - Login with wrong password returns error
   - Login with non-existent user returns error
   - Login returns CSRF token in response
   - JWT token can be used to access protected endpoints
   - Expired JWT token is rejected
   - Logout invalidates the session
   - Logout invalidates the JWT token
   - Multiple logins from same user coexist or are managed correctly
   - Login attempt with inactive/unconfirmed account fails
2. Use the test client and UserFactory
3. Test both cookie-based and header-based JWT validation

## Expected Outcome

- Authentication flow is fully validated
- Security edge cases are covered

## Priority

**High**

## Acceptance Criteria

- [ ] At least 10 test cases covering authentication
- [ ] Happy path: login → access → logout
- [ ] Error cases: wrong password, missing user, expired token
- [ ] JWT and session lifecycle tested
- [ ] All tests pass in CI
