# Task 014-4 — Update Login Flow to Require 2FA Code

## Parent User Story

[US-014 — Two-Factor Authentication (2FA)](../USER_STORIES/user_story_014.md)

## Description

Modify the login flow to require a TOTP code or recovery code when 2FA is enabled on the user's account.

## Work to be Done

1. Update `core/users/routes/login.py`:
   - After successful password validation, check `user.is_2fa_enabled`
   - If 2FA is enabled and no TOTP code is provided:
     - Return a 202 response indicating 2FA is required
     - Response: `{"requires_2fa": true, "message": "TOTP code required"}`
   - If 2FA code is provided:
     - Validate against TOTP secret
     - If recovery code is provided instead, validate and mark it as used
   - Only issue JWT/session after both password and 2FA are validated
2. Update the login form/schema to accept an optional `totp_code` field
3. Handle time-skew with `valid_window=1`

## Expected Outcome

- 2FA-enabled users must provide a valid TOTP code to log in
- Recovery codes work as a fallback

## Priority

**High**

## Acceptance Criteria

- [ ] Login without TOTP code returns 202 with `requires_2fa: true` for 2FA-enabled users
- [ ] Login with valid TOTP code completes authentication
- [ ] Login with invalid TOTP code is rejected
- [ ] Recovery codes can be used in place of TOTP
- [ ] Used recovery codes cannot be reused
- [ ] Non-2FA users are unaffected
