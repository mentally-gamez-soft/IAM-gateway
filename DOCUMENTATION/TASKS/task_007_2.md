# Task 007-2 — Configure SQLAlchemy Engine Options in App Factory

## Parent User Story

[US-007 — Database Connection Pooling and Health Monitoring](../USER_STORIES/user_story_007.md)

## Description

Pass the connection pool configuration to the SQLAlchemy engine via `SQLALCHEMY_ENGINE_OPTIONS` in the Flask app factory.

## Work to be Done

1. In `core/__init__.py`, before `db.init_app(app)`, set `SQLALCHEMY_ENGINE_OPTIONS`:
   ```python
   app.config["SQLALCHEMY_ENGINE_OPTIONS"] = {
       "pool_size": app.config.get("SQLALCHEMY_POOL_SIZE", 5),
       "max_overflow": app.config.get("SQLALCHEMY_MAX_OVERFLOW", 10),
       "pool_recycle": app.config.get("SQLALCHEMY_POOL_RECYCLE", 1800),
       "pool_pre_ping": app.config.get("SQLALCHEMY_POOL_PRE_PING", True),
       "pool_timeout": app.config.get("SQLALCHEMY_POOL_TIMEOUT", 30),
   }
   ```
2. Add logging for the engine options at startup (DEBUG level)
3. Verify the pool configuration is applied by examining the engine at runtime
4. Test that `pool_pre_ping` effectively detects stale connections

## Expected Outcome

- SQLAlchemy uses the configured pool settings
- Stale connections are detected and replaced via pre_ping
- Pool configuration is logged at startup

## Priority

**Medium**

## Acceptance Criteria

- [ ] `SQLALCHEMY_ENGINE_OPTIONS` is set before `db.init_app(app)`
- [ ] Engine uses the configured pool_size and max_overflow
- [ ] `pool_pre_ping` is active and detects stale connections
- [ ] Pool configuration is logged at DEBUG level during startup
- [ ] No errors when the database is temporarily unavailable (graceful reconnection)
