# Task 002-6 — Update Swagger Documentation for Password Reset

## Parent User Story

[US-002 — Password Reset / Forgot Password Flow](../USER_STORIES/user_story_002.md)

## Description

Update the Swagger/OpenAPI documentation to include the new `/forgot-password` and `/reset-password/<token>` endpoints with request/response schemas.

## Work to be Done

1. Add `POST /forgot-password` endpoint documentation to `static/swagger-docs/swagger.json`:
   - Request body schema: `{"email": "string"}`
   - Response 200 schema: `{"message": "string", "status": 200}`
2. Add `POST /reset-password/{token}` endpoint documentation:
   - Path parameter: `token` (string)
   - Request body schema: `{"password": "string"}`
   - Response 200 schema: success message
   - Response 422 schema: error details (expired token, invalid token, weak password)
3. Add descriptions and examples for each endpoint
4. Verify the updated Swagger UI renders correctly

## Expected Outcome

- Swagger documentation includes the new password reset endpoints
- API consumers can discover and understand the password reset flow from the docs

## Priority

**Medium**

## Acceptance Criteria

- [ ] Both endpoints appear in the Swagger UI
- [ ] Request and response schemas are accurate
- [ ] Error responses are documented with examples
- [ ] Swagger UI renders without errors after the update
