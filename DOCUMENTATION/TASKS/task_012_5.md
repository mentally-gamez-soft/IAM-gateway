# Task 012-5 — Add Swagger Documentation for GDPR Endpoints

## Parent User Story

[US-012 — GDPR Compliance Endpoints](../USER_STORIES/user_story_012.md)

## Description

Document all GDPR endpoints in the Swagger/OpenAPI specification.

## Work to be Done

1. Add GDPR endpoint entries to swagger spec:
   - `GET /user/data` — response schema with full data export structure
   - `DELETE /user/account` — request body schema (confirm + password) + response
   - `GET /user/consent` — consent list response schema
   - `PUT /user/consent` — consent update request/response schema
2. Add authentication requirements
3. Include example requests and responses
4. Document error responses (401, 403, 422)

## Expected Outcome

- GDPR endpoints are fully documented in Swagger

## Priority

**Low**

## Acceptance Criteria

- [ ] All GDPR endpoints appear in Swagger
- [ ] Request/response schemas are complete
- [ ] Authentication requirements are documented
- [ ] Example payloads are included
