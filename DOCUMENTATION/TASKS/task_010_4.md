# Task 010-4 — Replace Static Swagger Config with Dynamic Generation

## Parent User Story

[US-010 — OpenAPI Specification Auto-Generation](../USER_STORIES/user_story_010.md)

## Description

Remove the static `swagger.json` file and the manual `flask-swagger-ui` configuration, replacing them with the dynamically generated spec from `flask-smorest`.

## Work to be Done

1. Remove or deprecate `static/swagger-docs/swagger.json`
2. Remove `flask-swagger-ui` dependency from `pyproject.toml` (replaced by `flask-smorest` Swagger UI)
3. Remove or refactor `core/swagger/swagger_config.py`
4. Ensure `flask-smorest` serves the Swagger UI at `/swagger`
5. Ensure the OpenAPI spec JSON is available at `/openapi.json` (or configured path)
6. Add authentication scheme documentation to the spec (JWT Bearer)
7. Verify all endpoints appear correctly in the generated spec

## Expected Outcome

- Swagger documentation is fully auto-generated
- No manual JSON maintenance required
- Swagger UI serves the dynamic spec

## Priority

**Medium**

## Acceptance Criteria

- [ ] Static `swagger.json` is removed or archived
- [ ] `flask-swagger-ui` dependency is removed
- [ ] `flask-smorest` serves Swagger UI at `/swagger`
- [ ] OpenAPI spec is accessible as JSON at a known URL
- [ ] All API endpoints appear in the generated spec
- [ ] Authentication scheme is documented in the spec
